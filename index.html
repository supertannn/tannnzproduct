PUBLISH FROM YOUR FOLDER

Tambah produk tanpa token

TannProduct sekarang memakai folder statis. Tidak ada token, login, backend, Node.js, atau Supabase. File di folder publik akan bisa diunduh semua orang.

01
Letakkan file

Salin file .rbxm atau .rbxmx ke folder products/ di project, lalu commit/push ke GitHub.

02
Daftarkan produk

Tambahkan satu objek produk di array products.json pada root project. Nama file di filePath dan downloadUrl harus sama persis.

03
Deploy otomatis

Vercel akan deploy ulang setelah perubahan masuk ke branch yang terhubung. Produk baru muncul di katalog setelah deploy selesai.

Template untuk produk gratis
{
  "id": "my-new-model",
  "name": "Nama Produk",
  "description": "Deskripsi singkat produk.",
  "category": "Roblox Model",
  "type": "free",
  "price": 0,
  "version": "1.0.0",
  "format": "RBXMX",
  "filePath": "products/nama-file.rbxmx",
  "downloadUrl": "/products/nama-file.rbxmx",
  "purchaseUrl": "",
  "date": "2026-10-10",
  "accent": "violet"
}

Penting: situs statis tidak bisa mendeteksi file baru di folder secara otomatis. Setiap file baru harus didaftarkan di products.json. Jangan taruh file premium di folder products/ publik; gunakan tautan pembelian eksternal.
